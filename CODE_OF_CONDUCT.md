# Code of Conduct

FrameVitals is intended to be a constructive, technically serious open-source project.

## Expected behavior

Contributors and maintainers should:

- Be respectful and professional in technical disagreement.
- Critique ideas and code rather than people.
- Give actionable review feedback.
- Welcome good-faith questions from contributors with different experience levels.
- Avoid harassment, discrimination, threats, personal attacks, or deliberately disruptive behavior.
- Respect privacy and do not publish another person's private information without permission.

## Project spaces

This code of conduct applies to issues, pull requests, discussions, reviews, and other spaces used to represent the project.

## Enforcement

Behavior that violates these expectations may be edited, removed, locked, or otherwise moderated. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Concerns should be reported privately to the repository maintainer when possible. Reports will be handled with discretion and with attention to the safety of the people involved.
