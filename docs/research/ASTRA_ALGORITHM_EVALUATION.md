# Astra algorithm evaluation

Assessment date: 2026-10-15. Scientific methods revision 2. A new asymptotic result is a research candidate, not evidence of a practical FrameVitals speedup. Maintained built-in NumPy/SciPy/sklearn/NetworkX paths are preferred when they satisfy correctness, workload and resource requirements.

## Selection decisions

| Problem / candidate | Assumptions and evidence | Decision |
| --- | --- | --- |
| Weighted repeated SSSP: SciPy CSR Dijkstra | Nonnegative real edge costs, simple graph, existing depth budgets. Three seeded 20k-node sparse directed workloads, conversion included, NetworkX distance oracle; median 1.12→0.57 s in this environment. CSR O(V+E) storage and O(V) distance vector per source. | Accept for weighted graphs ≥20k nodes and ≥2V edges. Threshold is an engineering policy, not a universal optimal crossover. Preserve NetworkX multigraph behavior. |
| Unweighted CSR path execution | Initial 10k-node path experiment was slower after conversion/import. Final benchmark retains BFS; no unweighted CSR speedup is claimed. | Reject unweighted dispatch. Keep BFS, exact mean/max and bounded sampled quantiles. |
| Duan et al. 2025 directed SSSP | [Primary paper](https://arxiv.org/abs/2504.17033), nonnegative directed real costs, comparison-addition model, O(m log^(2/3)n). Recursive frontier/pivot machinery has substantially greater implementation burden than the existing library portfolio. | Defer. The asymptotic theorem is credible evidence of a bound; no representative FrameVitals implementation reproduction or crossover was established. No superiority claim, new kernel or renamed Dijkstra. |
| Duan et al. 2026 directed SSSP | [Primary preprint](https://arxiv.org/abs/2602.07868), O(m√log n+√(mn log n log log n)), same nonnegative real-cost restriction. | Defer before integration: no maintained production reference and replicated end-to-end advantage were established in this audit. Theorem and empirical performance remain distinct. |
| A* | Requires a target and an admissible heuristic for optimality; diagnostics summarize many source-to-all reachable distances. Deriving and validating heuristics/preprocessing would be extra work. | Reject for this all-target summary. It could suit a future spatial point-to-point API. |
| Bellman–Ford / negative-weight SSSP | Supports directed negative costs absent reachable negative cycles; O(VE), expensive under present large-graph budgets. Existing API deliberately rejects explicitly requested invalid Dijkstra weights and labels auto BFS fallback. | Defer separate negative-cost API. Do not silently replace weighted semantics or hide negative cycles. |
| Randomized SVD | [Halko–Martinsson–Tropp](https://arxiv.org/abs/0909.4061); low-rank structure favors a bounded subspace. Existing sklearn implementation, seed/power count fixed. Four seeded rank-six matrices compared with full SVD; top six and stable rank match within 1e−10; residual exposed. | Retain with population/residual metadata. Reject full-matrix rank claims from sampled submatrices. No claimed universal speedup or probabilistic error interval. |
| Deterministic strided submatrix | Cheap, but periodic diagonal oracle aliases. No general rank accuracy guarantee. | Replace by seeded uniform row/column sampling; still no unbiased population-rank claim. |
| Energy distance for univariate drift | [SciPy method/reference](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.energy_distance.html), finite first absolute moment for population interpretation. Sorting avoids quadratic pair matrices. Independent values verified against SciPy. | Accept descriptive effect alongside Wasserstein/KS. No inferred p-value and no universal alternative superiority. |
| Kernel MMD / multivariate energy permutation tests | Kernel bandwidth, independence and resampling calibration needed. Exact kernel MMD typically O(N²) storage/work; linear/random-feature alternatives add estimator choices. | Defer: present per-column API does not justify default multivariate cost or an unvalidated bandwidth heuristic. |
| BY versus BH multiplicity control | [SciPy and cited original work](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.false_discovery_control.html). Column hypotheses can be dependent. Differential BH/BY golden tests use independent official implementation. | Accept BY for returned valid hypothesis family. Conservative under many settings; not correction for invalid marginal tests or heuristic severity rules. |
| BCa versus closed-form intervals | [SciPy bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html). BCa can be degenerate and memory-heavy; Student-t exactness requires Gaussian IID samples. | Retain fast t/order-statistic route, research BCa with bounded batches and validity fallback. Do not label all t intervals exact. |
| Log quantiles / DDSketch-inspired representative | [Masson–Rim–Lee](https://arxiv.org/abs/1908.10693). Endpoint derivation yields α relative bound away from zero; Python/Rust boundary and merge tests. | Correct existing kernel. Do not introduce a second sketch dependency or claim full DDSketch collapsing semantics. |
| More anomaly detectors / neural ensemble | Existing robust/projection, IF/LOF/covariance and optional ECOD/COPOD/reconstruction views. Planted Gaussian tails are easy; additional detectors do not establish general accuracy gains. | No detector-count expansion. Correct voting/transform consistency and retain explicit relative-score limitations. Broader precision/recall and seed studies remain open. |
| Health-score replacement | No labelled cross-domain calibration dataset or agreed domain loss exists. Sparsity, low rank and disconnectedness can be intended. | Reject arbitrary reweighting. Expose heuristic basis, component formula and critical findings. A calibrated score is a future empirical project. |

## Reproduction and limits

Run `benchmarks/astra_science.py --before <Sol-worktree> --after . --output docs/benchmarks/astra-results.json` using the same interpreter, one BLAS thread and seeded inputs. Raw runs include time, process peak RSS, separately measured Python allocations and accuracy diagnostics. Three seeds are repeated fresh processes; they quantify observed variability, not a statistical performance guarantee across machines. The benchmark deliberately reports inference overhead and neutral/slower results as well as the weighted graph gain.

Recent SSSP methods failed the current practical reproduction/integration gate and remain research backlog items. Their published bounds are not disputed. This report does not claim to reproduce those papers' experimental results or to establish a 2025/2026 state-of-the-art implementation.
