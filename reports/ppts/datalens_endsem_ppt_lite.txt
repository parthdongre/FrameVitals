  •  Existing tools are split: profiling-only (ydata), drift-only
     (Evidently), ML-only (AutoML). None do all three.

SLIDE 5  ·  DEEP STATISTICS — UNIVARIATE FORMULAE
────────────────────────────────────────────────────────────────────────────────

Per numeric column.

  •  Skew   γ₁  =  E[(X − μ)³] / σ³        |γ₁| < 0.5 symmetric · ≥ 1 highly skewed
  •  Kurt   γ₂  =  E[(X − μ)⁴] / σ⁴ − 3    > 1 heavy · < −1 light tailed

  •  Normality:  Shapiro-Wilk (n ≤ 5000) · D'Agostino-Pearson (n ≥ 20) ·
                 Anderson-Darling vs 5 % critical.

  •  Best-fit distribution by AIC across {norm, lognorm, expon, gamma,
     weibull, beta}:
        AIC = 2·k − 2·ln L̂

  •  Bootstrap 95 % CIs (mean & median): 999 BCa resamples
     (scipy.stats.bootstrap).


────────────────────────────────────────────────────────────────────────────────
SLIDE 6  ·  DEEP STATISTICS — BIVARIATE FORMULAE
────────────────────────────────────────────────────────────────────────────────

  Numeric × numeric:
      Pearson r   =  Cov(X,Y) / (σ_X · σ_Y)        ∈ [−1, 1]
      Spearman ρ  =  Pearson r on ranks
      Kendall τ   =  P(concordant) − P(discordant)

  Categorical × categorical:
      χ²          =  Σ (Oᵢ − Eᵢ)² / Eᵢ
      Cramér V    =  √( χ² / (n · (min(r, c) − 1)) )    ∈ [0, 1]
                     ≥ 0.5 strong · ≥ 0.3 moderate · ≥ 0.1 weak

  Binary × numeric:
      Point-biserial r_pb = Pearson r with binary coded {0, 1}

  Group difference:
      Mann-Whitney U (2 groups) · Kruskal-Wallis H (≥ 3 groups)

SLIDE 7  ·  ANOMALY ENSEMBLE
────────────────────────────────────────────────────────────────────────────────

Each detector emits a [0, 1] score after min-max normalisation.

  •  Isolation Forest  score(x) = 2^(−E[h(x)] / c(n))
  •  Local Outlier Factor  LOF_k(x) = mean(lrd(y) / lrd(x), y ∈ N_k(x))
  •  Robust z (MAD)  z* = (x − median) / (1.4826·MAD), flag |z*| > 3.5
  •  Mahalanobis  D²(x) = (x − μ)ᵀ Σ⁻¹ (x − μ),  Σ from MinCovDet
  •  Elliptic Envelope — robust Gaussian envelope
  •  Optional ECOD + COPOD (pyod)

Ensemble:  s(x) = mean across available detectors;  flag if s ≥ 0.6.

SLIDE 9  ·  ML LAB — METRICS
────────────────────────────────────────────────────────────────────────────────

7-model leaderboard, StratifiedKFold(5) for clf, KFold(5) for reg.

Classification:
   Accuracy = (TP + TN) / N
   Precision = TP / (TP + FP)        Recall = TP / (TP + FN)
   F1 = 2·P·R / (P + R)              F1_weighted = Σ wᵢ · F1ᵢ
   Brier = (1/n) Σ (pᵢ − yᵢ)²        (binary calibration)

Regression:
   R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²
   MAE = (1/n) Σ |yᵢ − ŷᵢ|
   RMSE = √ (1/n) Σ (yᵢ − ŷᵢ)²

Winner refit on train + 25 % holdout validation.


────────────────────────────────────────────────────────────────────────────────
SLIDE 10  ·  ML LAB — SHAP
────────────────────────────────────────────────────────────────────────────────

Shapley value (Lundberg & Lee 2017):

   φᵢ(x)  =   Σ      |S|! (|F| − |S| − 1)!  ·  [ v(S∪{i}) − v(S) ]
            S ⊆ F\{i} ───────────────────
                            |F|!

   Sums to ŷ(x) − E[ŷ] (local accuracy).

  •  shap.TreeExplainer — exact SHAP for tree ensembles.
  •  shap.LinearExplainer — closed-form SHAP for linear models.
  •  Permutation importance — fallback, drop in score when feature j is
     randomly permuted.

Outputs: top-15 global features (one-hot summed back), top-3 per-row
stories, beeswarm summary PNG.

SLIDE 11  ·  TIME-SERIES MODULE
────────────────────────────────────────────────────────────────────────────────

  Date detection:
      score = 0.6·parse_rate + 0.3·monotone + 0.1·name_is_date_like
      Period via FFT: round(n / argmax|RFFT(series − mean)|).

  Stationarity:
      ADF  H₀: unit root → reject (p < 0.05) means stationary
      KPSS H₀: stationary → fail to reject (p > 0.05) means stationary

  STL strengths:
      F_T = max(0, 1 − Var(R) / Var(T + R))
      F_S = max(0, 1 − Var(R) / Var(S + R))

  Holt-Winters (additive):
      ℓ_t = α(y_t − s_{t−m}) + (1 − α)(ℓ_{t−1} + b_{t−1})
      ŷ_{t+h} = ℓ_t + h·b_t + s_{t+h−m}
   compared against a last-value naive baseline by MAE / RMSE.

SLIDE 12  ·  TEXT PROFILE & DRIFT
────────────────────────────────────────────────────────────────────────────────

text_profile.py
  •  Type-Token Ratio  TTR = |V| / N
  •  TF-IDF  tfidf(t,d) = count(t,d) · log[ |D| / |{d : t∈d}| ]
  •  LSA — TruncatedSVD(2) on the TF-IDF matrix.
  •  Sentiment-lite polarity = (pos_words − neg_words) / total_words.
  •  Regex hits: emails, URLs, phones, mentions, hashtags, monetary.

drift_analysis.py
  •  PSI  = Σ_b (p_b^cur − p_b^ref) · ln(p_b^cur / p_b^ref)
            buckets: <0.10 stable · <0.25 minor · <0.50 moderate · ≥0.50 severe.
  •  Two-sample KS  = max_x |F_ref(x) − F_cur(x)|, flag p < 0.01.
  •  Categorical drift: chi-square independence on the 2 × K table.

SLIDE 15  ·  LIMITATIONS, FUTURE & CONCLUSION
────────────────────────────────────────────────────────────────────────────────

Limitations:
  •  Default hyperparameters — leaderboard is a baseline.
  •  Drift compares two halves; no persistent baseline.
  •  In-memory pipeline; degrades > 1 M rows.
  •  English-centric NLP.

Future:
  •  Persistent drift baselines; streaming / sampled deep stats.
  •  Optuna hyperparameter tuning.
  •  Causal inference (DoWhy / EconML).
  •  LLM agent re-call into pandas when retrieval is empty.

Conclusion:
  •  Working integration of profiling, deep statistics, anomaly detection,
     ML, SHAP, time-series, drift, and an LLM agent in one pipeline.
  •  Every claim traces to a named algorithm and a concrete formula.
  •  Ships with a 27-page module reference covering the math behind every
     analytical module.
