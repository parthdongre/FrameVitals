\section{Glossary -- metrics, tests, and algorithms used downstream}
\label{sec:glossary}

The dashboard surfaces a lot of statistics. The definitions live here once,
so module entries can refer to them without repeating themselves.

\subsection{Regression metrics}

\textbf{$R^2$ (coefficient of determination).} Fraction of variance in the
target explained by the model.
\[
R^2 \;=\; 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}
\]
$R^2 = 1$ is perfect, $R^2 = 0$ matches a constant-mean predictor, $R^2 < 0$
means the model is worse than predicting the mean.

\textbf{MAE -- Mean Absolute Error.}
$\mathrm{MAE} = \tfrac{1}{n}\sum_i |y_i - \hat{y}_i|$.
Same units as the target. Robust to outliers.

\textbf{MSE -- Mean Squared Error.}
$\mathrm{MSE} = \tfrac{1}{n}\sum_i (y_i - \hat{y}_i)^2$.
Penalises large errors more than small ones.

\textbf{RMSE.} $\mathrm{RMSE} = \sqrt{\mathrm{MSE}}$. Same units as the target.

\textbf{Residuals.} $r_i = y_i - \hat{y}_i$. The dashboard reports
\code{mean}, \code{median}, \code{std}, \code{min}, \code{max} on residuals;
a near-zero mean and symmetric tails indicate an unbiased model.

\subsection{Classification metrics}

\textbf{Accuracy.} Fraction of predictions that are correct. Misleading on
imbalanced classes (a 91\%-negative dataset trivially scores 0.91 by always
predicting "no default").

\textbf{Precision, recall, $F_1$ (per class).}
\[
P = \tfrac{TP}{TP+FP}, \quad
R = \tfrac{TP}{TP+FN}, \quad
F_1 = \tfrac{2 P R}{P + R}.
\]

\textbf{Weighted F1 / precision / recall.} Per-class score weighted by class
support. The default ranking metric for the leaderboard on classification
tasks.

\textbf{Confusion matrix.} A $K \times K$ table of true class (rows) vs
predicted class (columns). Diagonal = correct predictions.

\textbf{Brier score.} Mean squared error on predicted probabilities for a
binary target:
$\mathrm{Brier} = \tfrac{1}{n}\sum_i (p_i - y_i)^2$. Lower is better; $0$ is
perfectly calibrated, $0.25$ corresponds to random guessing.

\subsection{Cross-validation}

\textbf{KFold ($K=5$).} Splits the data into 5 equal folds; trains on 4,
tests on the held-out 1, rotates 5 times. Reports mean and standard
deviation of the metric.

\textbf{StratifiedKFold.} KFold that preserves the class distribution in
each fold. Used for classification. The number of splits is automatically
capped at $\min(K, \text{smallest class size})$.

\textbf{Holdout.} A single 75\%/25\% train/test split. Used by
diagnostics modules for confusion matrices, residuals, Brier score.

\subsection{Distribution and normality tests}

\textbf{Skewness.} Third standardized moment.
$|\text{skew}| < 0.5$ symmetric, $0.5\!-\!1$ moderate, $>1$ highly skewed.

\textbf{Kurtosis (excess).} Fourth standardized moment minus 3.
$>1$ heavy-tailed, $<-1$ light-tailed, otherwise near-normal.

\textbf{Shapiro--Wilk.} Most powerful normality test for small samples
($n \leq 5000$). $p < 0.05$ rejects normality.

\textbf{D'Agostino--Pearson.} Combines skew + kurtosis tests; works well for
$n \geq 20$.

\textbf{Anderson--Darling.} Statistic compared against critical values at
$\{15, 10, 5, 2.5, 1\}$\% significance levels. The dashboard reports the
$5\%$ critical value: if statistic $>$ critical, reject normality.

\textbf{Best-fit distribution.} For each candidate distribution
($\text{Normal}, \text{Lognormal}, \text{Exponential}, \text{Gamma},$
$\text{Weibull}, \text{Beta}$) fit by MLE, then rank by
$\mathrm{AIC} = 2k - 2\ln\hat{L}$, where $k$ is the number of parameters
and $\hat{L}$ is the maximised likelihood. Lower AIC wins.

\subsection{Outlier detection rules}

\textbf{IQR (Tukey's fences).} Define $Q_1, Q_3$, $\mathrm{IQR} = Q_3 - Q_1$.
Outlier if value is below $Q_1 - 1.5\,\mathrm{IQR}$ or above
$Q_3 + 1.5\,\mathrm{IQR}$.

\textbf{Classical $z$-score.} $z_i = (x_i - \bar{x}) / \sigma$;
$|z| > 3$ flagged.

\textbf{Robust (MAD) $z$.} Uses median and median absolute deviation:
$z^*_i = (x_i - \text{median}) / (1.4826 \cdot \text{MAD})$;
$|z^*| > 3.5$ flagged. The constant $1.4826$ makes the MAD a consistent
estimator of $\sigma$ for normal data.

\textbf{Mahalanobis distance.}
$D^2 = (\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1}
(\mathbf{x} - \boldsymbol{\mu})$. Captures multivariate outliers using the
inverse covariance matrix; estimated robustly via the Minimum Covariance
Determinant.

\textbf{Isolation Forest.} Builds random binary trees; anomalies have
shorter average path length to a leaf because they are easier to isolate.
Score $\in [0, 1]$, higher is more anomalous.

\textbf{Local Outlier Factor (LOF).} Density-based -- compares each row's
local reachability density to its $k$-nearest neighbours. Score $> 1$ means
locally less dense, i.e.\ more anomalous.

\textbf{Elliptic Envelope.} Fits a robust Gaussian; flags rows in the tails
of the implied ellipse.

\textbf{ECOD / COPOD.} Empirical / copula-based outlier detection from
\code{pyod}. Distribution-free, no neighbour search needed.

\subsection{Correlation and association}

\textbf{Pearson $r$.} Linear correlation $\in [-1, 1]$.
$r = \mathrm{Cov}(X, Y) / (\sigma_X \sigma_Y)$. Sensitive to outliers.

\textbf{Spearman $\rho$.} Pearson on ranks; monotonic correlation.

\textbf{Kendall $\tau$.} Probability of concordant minus discordant pairs.

\textbf{$p$-value.} Probability of seeing a correlation at least this
extreme if the true correlation were $0$. $p < 0.05$ is the default
"significant" threshold.

\textbf{Chi-square test of independence.} For two categorical variables,
$\chi^2 = \sum (\mathrm{observed} - \mathrm{expected})^2 / \mathrm{expected}$
on the contingency table.

\textbf{Cramer's $V$.} Categorical-categorical association strength derived
from $\chi^2$:
$V = \sqrt{\chi^2 / (n \cdot (\min(r,c) - 1))}$, $\in [0, 1]$.
Buckets: $\geq 0.5$ Strong, $\geq 0.3$ Moderate, $\geq 0.1$ Weak.

\textbf{Point-biserial $r$.} Pearson correlation between a binary variable
(coded $0/1$) and a continuous one. Same scale as Pearson.

\textbf{Mann--Whitney U.} Rank-based test that two independent samples come
from the same distribution. Non-parametric version of the two-sample
$t$-test.

\textbf{Kruskal--Wallis H.} Mann--Whitney generalised to $\geq 3$ groups.

\subsection{Stationarity tests (time-series)}

\textbf{ADF (Augmented Dickey--Fuller).}
$H_0$: a unit root is present (non-stationary). $p < 0.05$ rejects $H_0$,
i.e.\ the series is stationary.

\textbf{KPSS.} $H_0$: the series is (trend-)stationary. $p > 0.05$ fails to
reject stationarity. Combining ADF and KPSS gives one of four verdicts:
stationary, non-stationary, trend-stationary, difference-stationary.

\textbf{ACF / PACF.} Autocorrelation function and partial autocorrelation
function up to lag $\min(40, n/5)$. Slow-decaying ACF signals
non-stationarity; spikes at lag $k$ in the PACF suggest an AR$(k)$ model.

\textbf{STL decomposition.} Seasonal-Trend decomposition using LOESS.
Splits the series into trend $T_t$, seasonal $S_t$, and residual $R_t$
components. Strength scores (Hyndman, 2008) are
\[
F_T = \max\!\left(0, 1 - \frac{\mathrm{Var}(R_t)}{\mathrm{Var}(T_t + R_t)}\right),
\quad
F_S = \max\!\left(0, 1 - \frac{\mathrm{Var}(R_t)}{\mathrm{Var}(S_t + R_t)}\right).
\]

\textbf{Holt--Winters (additive).} Triple exponential smoothing with
trend + seasonality. Compared against a "last-value" naive baseline using
MAE and RMSE on the held-out tail.

\subsection{Drift metrics}

\textbf{PSI -- Population Stability Index.} For two distributions binned
into $B$ buckets,
\[
\mathrm{PSI} \;=\; \sum_{b=1}^{B} (p_b^{(\mathrm{cur})} - p_b^{(\mathrm{ref})})\,
\ln \frac{p_b^{(\mathrm{cur})}}{p_b^{(\mathrm{ref})}}.
\]
Buckets: $<0.10$ stable, $<0.25$ minor, $<0.50$ moderate, $\geq 0.50$ severe.

\textbf{Kolmogorov--Smirnov two-sample.} Maximum absolute difference between
the two empirical CDFs. $p < 0.01$ flags a real distribution shift.

\textbf{Chi-square (drift).} Same as above but applied to the count
contingency table of categorical proportions in the two halves.

\textbf{Mean $z$-shift.} $(\bar{x}_{\mathrm{cur}} - \bar{x}_{\mathrm{ref}}) / \sigma_{\mathrm{pooled}}$.
A simple "how many SDs has the mean moved?" view.

\subsection{Regression diagnostics for ML features}

\textbf{VIF -- Variance Inflation Factor.} For feature $j$ regressed on all
others, $\mathrm{VIF}_j = 1 / (1 - R^2_j)$. $\mathrm{VIF} \geq 10$ is high
multicollinearity; $\geq 5$ is moderate.

\textbf{Mutual information.} Information-theoretic dependency, $\geq 0$,
not bounded above. Captures both linear and non-linear relationships.

\textbf{Permutation importance.} Drop in the model's score when a single
feature's values are randomly permuted. Run over $n$ repeats; mean +
standard deviation reported.

\subsection{Explainability}

\textbf{SHAP value.} Per row, per feature contribution to the model's
output, derived from cooperative game theory (Shapley values). Sums to
$\hat{y} - \mathrm{baseline}$. Mean absolute SHAP across rows gives global
feature importance; the per-row vector tells the story for one prediction.

\textbf{Tree SHAP.} Exact, polynomial-time SHAP for tree ensembles
(Random Forest, Gradient Boosting, XGBoost, LightGBM).

\textbf{Linear SHAP.} Closed-form SHAP for linear models given a background
sample.

\subsection{Information-theory and embeddings (for text / RAG)}

\textbf{Shannon entropy.} For category proportions $p_i$,
$H = -\sum_i p_i \log_2 p_i$. Maximum is $\log_2 K$ (uniform). Entropy ratio
is $H / \log_2 K$, a value in $[0, 1]$ where $1$ is "perfectly uniform".

\textbf{TF-IDF.} Term frequency divided by inverse document frequency.
Down-weights terms that appear in many documents.

\textbf{TruncatedSVD (LSA).} Truncated singular value decomposition on the
TF-IDF matrix to project documents into a low-dimensional latent space
(2 components for the dashboard scatter).

\textbf{PSI vs KL divergence.} PSI is symmetric:
$\sum_b (p_b - q_b) \ln(p_b/q_b)$ vs KL $\sum_b p_b \ln(p_b/q_b)$. Both
become large when the distributions diverge, but PSI is finite when both
sides have non-zero coverage.

\section{Orchestration \& I/O}

\subsection{\texttt{\textbf{pipeline.py}} \textcolor{tealac}{\small\textsf{[phase orchestrator]}}}

Single entry point that runs the entire analysis. Phase boundaries are
explicit so failures in one phase cannot poison the others.

\begin{libsbox}
\begin{itemize}
  \item \code{concurrent.futures.ThreadPoolExecutor} -- parallel phase 3.
  \item \code{logging} -- structured pipeline logs.
  \item \code{time.perf_counter} -- millisecond timings per phase.
  \item Internal: every other module in \code{modules/}.
\end{itemize}
\end{libsbox}

\begin{algobox}
\begin{enumerate}
  \item \textbf{Phase 1 -- Structural.} \code{load_dataset} $\to$
        \code{build_profile} $\to$ \code{infer_column_roles} $\to$
        \code{summarize_roles} $\to$ \code{detect_dataset_signals} $\to$
        \code{select_analyses}.
  \item \textbf{Phase 2 -- Quality.} \code{calculate_health_score} $\to$
        \code{calculate_ml_readiness} $\to$ \code{calculate_advanced_indicators}.
  \item \textbf{Phase 3 -- Parallel analytics} (mode $\in$ \{\code{standard},
        \code{deep}, \code{research}\}). Wrapped in \code{_safe_call}: deep
        statistics v2, anomaly ensemble, time-series, text profile.
        Default \code{parallel_workers=4}.
  \item \textbf{Phase 4 -- ML chain} (only if \code{target_column} given).
        \code{run_model_leaderboard} $\to$ \code{explain_winner}.
  \item \textbf{Phase 5 -- Display + cleaning.} \code{build_signals} $\to$
        \code{create_cleaned_dataset} $\to$ \code{generate_charts}.
  \item \textbf{Phase 6 -- AI report.} Deferred unless
        \code{DATALENS_ANALYZE_AI=1}. The dashboard fetches it on demand
        through \code{/api/ai-report}.
\end{enumerate}
Every parallel branch is wrapped so a single exception turns into
\code{\{available: false, error: ...\}} instead of sinking the run.
\end{algobox}

\begin{outbox}
Single dict with: \code{dataset_id}, \code{filename}, \code{analysis_mode},
\code{profile}, \code{column_roles}, \code{roles_summary},
\code{dataset_signals}, \code{analysis_selection}, \code{health},
\code{signals}, \code{ml_readiness}, \code{advanced},
\code{deep_statistics_v2}, \code{anomalies_v2}, \code{model_leaderboard},
\code{explainability}, \code{time_series}, \code{text_profile},
\code{cleaning}, \code{charts}, \code{ai_report}, and a \code{timings_ms}
map keyed by phase.
\end{outbox}

\predicts every phase fires green. \code{timings_ms.total} typically lands
in 25--45 s on a laptop because phase 3 alone spawns four threads doing
real work and the leaderboard runs CV on 5--7 models.

\subsection{\texttt{\textbf{loader.py}} \textcolor{tealac}{\small\textsf{[file ingestion]}}}

Reads the uploaded CSV / TSV / XLSX / XLS / JSON. Tolerates real-world
encodings.

\begin{libsbox}
\begin{itemize}
  \item \code{pandas.read_csv}, \code{read_excel}, \code{read_json}.
  \item \code{pathlib.Path}, \code{uuid.uuid4} for the dataset id.
  \item Internal \code{security.validate_file} +
        \code{security.make_safe_filename}.
\end{itemize}
\end{libsbox}

\begin{algobox}
For CSV/TSV reads, an encoding waterfall is tried until one succeeds:
\code{utf-8-sig} $\to$ \code{windows-1252} $\to$ \code{latin-1}. If all
three fail, a final \code{latin-1} read with \code{errors='replace'}
guarantees the file loads, possibly with garbled non-ASCII characters.
\end{algobox}

\predicts loads cleanly as UTF-8; returns a \code{(10110, 32)} dataframe
with no encoding fallback fired.

\subsection{\texttt{\textbf{security.py}} \textcolor{tealac}{\small\textsf{[guardrails]}}}

\begin{libsbox}
\code{werkzeug.utils.secure_filename}, plus a small extension allow-list.
\end{libsbox}

\begin{algobox}
\begin{enumerate}
  \item \code{validate_file(filename)} rejects anything outside

  \item \code{make_safe_filename(name)} strips path separators and

  \item \code{sanitize_csv_value(v)} prefixes a single quote to any cell

\end{enumerate}
\end{algobox}

\predicts no rejections; the cleaned export keeps every row.

\subsection{\texttt{\textbf{frontend\_api.py}} \textcolor{tealac}{\small\textsf{[dashboard payload assembler]}}}

\subsection{\texttt{\textbf{column\_roles.py}} \textcolor{tealac}{\small\textsf{[multi-label semantic roles]}}}

Assigns a \emph{set} of semantic roles to every column. Pure pandas /
regex; no ML.

\begin{libsbox}
\code{pandas}, \code{numpy}, \code{re}.
\end{libsbox}

\begin{algobox}
For each column, role assignment is driven by:
\begin{itemize}
  \item \textbf{Dtype} $\to$ \code{numeric}, \code{boolean},
        \code{categorical}.
  \item \textbf{Cardinality.} \code{constant} ($\leq 1$ unique),
        \code{binary} ($=2$), \code{low_cardinality} ($2$--$10$),
        \code{high_cardinality} (unique\_ratio $> 0.80$),
        \code{unique_like} ($> 0.95$).

\subsection{\texttt{\textbf{deep\_statistics\_v2.py}} \textcolor{tealac}{\small\textsf{[research-grade battery]}}}

\begin{libsbox}
\code{pandas}, \code{numpy}, \code{scipy.stats}: \code{shapiro},
\code{normaltest}, \code{anderson}, \code{bootstrap},
\code{pearsonr}, \code{spearmanr}, \code{kendalltau},
\code{pointbiserialr}, \code{mannwhitneyu}, \code{kruskal},
\code{chi2_contingency}, plus distributions
\code{norm, lognorm, expon, gamma, weibull_min, beta}.
\end{libsbox}

\begin{algobox}
Per numeric column:
\begin{enumerate}
  \item Descriptives: count, mean, median, std, min, max, $Q_1$, $Q_3$,
        IQR, skew, kurtosis with labels.
  \item \textbf{Three outlier views}: IQR ($1.5\cdot\mathrm{IQR}$ fences),
        classical $z$-score ($|z|>3$), robust MAD-$z$ ($|z^*|>3.5$).
  \item \textbf{Normality.} Shapiro--Wilk for $n\le 5000$; D'Agostino--Pearson

  \item \textbf{Distribution fit.} Fits each candidate by MLE, scores by

        degenerate data.
\end{enumerate}
Per categorical column:
\begin{itemize}
  \item Top-10 value counts + Shannon entropy and entropy ratio.
\end{itemize}
Bivariate (capped at \code{max_pairs=20} per type to bound runtime):
\begin{itemize}
  \item Numeric pairs: Pearson, Spearman, Kendall (all with $p$-values).
  \item Categorical pairs: $\chi^2$ + Cramer's $V$ (contingency tables
        capped at 30 categories per side).
  \item Binary categorical vs numeric: point-biserial (encodes the binary
        as $\{0, 1\}$).
  \item Group differences: Mann--Whitney U for 2 groups, Kruskal--Wallis H
        for 3--12 groups.
\end{itemize}

NaN and Inf.
\end{algobox}

\subsection{\texttt{\textbf{anomaly\_ensemble.py}} \textcolor{tealac}{\small\textsf{[6+ detectors, mean ensemble]}}}

\code{sklearn.ensemble.IsolationForest},

\code{sklearn.preprocessing.StandardScaler}.
Optional: \code{pyod.models.ecod.ECOD},
\code{pyod.models.copod.COPOD}.
\end{libsbox}

\begin{algobox}
\begin{enumerate}
  \item \textbf{Prepare matrix.} Drop constant numerics, cap to 30 columns
        (keep the most populated), median-impute missing, then
        \code{StandardScaler}.
  \item Run each detector and produce a $[0, 1]$ score:
  \begin{itemize}
    \item \emph{Isolation Forest} -- 200 trees, contamination
          configurable (default 5\%), $n_{\text{jobs}}=-1$. Score is
          $-\code{score_samples}$ min--max scaled.
    \item \emph{Local Outlier Factor} --
          $n_{\text{neighbors}}=\min(20, \max(5, n/20))$.
          Score is $-\code{negative_outlier_factor_}$ min--max scaled.
    \item \emph{Elliptic Envelope} -- robust Gaussian fit.
    \item \emph{MAD robust z} -- per-row mean of $|x - \tilde{x}| / (1.4826\cdot\mathrm{MAD})$ across columns.

          covariance, fallback to plain covariance with
          $\boldsymbol{\Sigma}^{-1}$ regularised by $10^{-6}\,I$.
    \item \emph{ECOD / COPOD} -- when \code{pyod} is installed.
  \end{itemize}
  \item \textbf{Ensemble.} Per-row mean across all available detectors.
  \item \textbf{Flagging.} Rows with ensemble score $\geq$ \code{threshold}
        (default 0.6).
\end{enumerate}
\end{algobox}

\begin{outbox}
\code{available}, \code{n_rows_scored}, \code{used_columns},
\code{detectors_run}, \code{threshold}, \code{contamination},
\code{flagged_count}, \code{ensemble_summary} (min/mean/median/max/p95/p99),

\section{Time, Text, Drift}

\subsection{\texttt{\textbf{time\_series.py}} \textcolor{tealac}{\small\textsf{[auto-detect $\to$ STL $\to$ forecast]}}}

\begin{libsbox}
\code{pandas}, \code{numpy};
\code{statsmodels.tsa.stattools.adfuller} / \code{kpss},
\code{statsmodels.tsa.stattools.acf} / \code{pacf},
\code{statsmodels.tsa.seasonal.STL},
\code{statsmodels.tsa.holtwinters.ExponentialSmoothing}.
\end{libsbox}

\begin{algobox}
\begin{enumerate}
  \item \textbf{Date detection.} For each column, compute parse rate via
        \code{pd.to_datetime(..., errors="coerce", format="mixed")}, and
        a monotone score = $\max($fraction increasing, fraction
        decreasing$)$. Reject low-cardinality numeric columns whose name
        is not date-like (so binary integers don't get parsed as
        nanosecond epochs). Score = $0.6 \cdot \text{parse rate} + 0.3 \cdot \text{monotone} + 0.1 \cdot \mathbb{1}[\text{name is date-like}]$.
        Highest score wins.
  \item \textbf{Frequency inference.} Compute the median inter-arrival
        time in seconds and bucket into \{second, minute, hour, day,
        week, month, quarter, year, irregular\}. Also try
        \code{pd.infer_freq(parsed.head(200))}.
  \item \textbf{Numeric series picker.} If a target is given and numeric,
        use it. Otherwise pick the highest-variance non-ID numeric
        column.
  \item \textbf{Stationarity.} ADF (\code{autolag="AIC"}) and KPSS
        (\code{regression="c", nlags="auto"}). Combine to one of
        \{stationary, non-stationary, trend-stationary,
        difference-stationary, inconclusive\}.
  \item \textbf{Period via FFT.} Compute the real-FFT magnitude
        spectrum, ignore DC, pick the dominant peak, $\text{period}
        = \mathrm{round}(n / \mathrm{peak})$. Sanity-bound by frequency
        label.
  \item \textbf{STL decomposition.} \code{STL(series, period=period,
        robust=True).fit()}; report trend / seasonal / residual
        previews and Hyndman strength scores $F_T, F_S$.
  \item \textbf{Autocorrelation.} ACF + PACF up to
        $\min(40, n/5)$ via \code{acf(..., fft=True)} and \code{pacf}.
  \item \textbf{Forecast.} Holt--Winters additive trend, additive
        seasonality if $\text{period}\geq 2$ and $n \geq 2\,\text{period}$.
        Train on $n - h$ rows where $h = \min(\max(\text{period}, 12),
        n/4)$. Naive baseline = last value. Report MAE + RMSE for both.
\end{enumerate}
\end{algobox}

\predicts detected column \code{application_date}; frequency label
\code{day} (median 1 day inter-arrival); period $\sim$7 (weekly);
paired numeric \code{loan_amount} (highest variance non-ID column);
ADF + KPSS verdict \emph{trend-stationary}; HW beats naive on MAE.

\subsection{\texttt{\textbf{text\_profile.py}} \textcolor{tealac}{\small\textsf{[TF-IDF + LSA preview]}}}

\begin{libsbox}
\code{re}, \code{collections.Counter}, \code{numpy}, \code{pandas};
\code{nltk.corpus.stopwords} when available (falls back to a built-in
list of $\sim$80 stopwords);
\code{sklearn.feature_extraction.text.TfidfVectorizer},
\code{sklearn.decomposition.TruncatedSVD}.
\end{libsbox}

\begin{algobox}
\textbf{Detection.} A column is text-like when:
object/string dtype and $\geq 30\%$ of values have $\geq 2$ tokens and
average length $\geq 8$ chars and (high cardinality but avg length
$\geq 20$ chars or any cardinality with avg length $\geq 8$ chars).

For up to 5 detected columns:
\begin{enumerate}
  \item Length stats via \code{str.len()}: average, min, max, median.
  \item Tokenisation: \code{re.findall(r"\textbackslash b[\textbackslash w'-]+\textbackslash b", lower)}.
        Stopwords filtered when computing top terms.
  \item Vocabulary stats: total tokens, vocab size, lexical diversity
        $= |V|/N$.
  \item Avg sentence length: split on \code{[.!?]} and count tokens per
        sentence.
  \item Top 15 unigrams + top 12 bigrams via \code{Counter}.
  \item Pattern hits via regex: emails, URLs, phone-like numbers,
        mentions, hashtags, monetary tokens. Reports row-counts +
        examples.
  \item Language guess (heuristic): ASCII fraction + English-stopword
        overlap classify the column as English / Latin-non-English /
        non-Latin / unknown.
  \item Sentiment-lite: ratio of words from a small positive seed list
        ($\{$\code{great, love, helpful, smooth, fast, useful, ...}$\}$)
        and a negative one
        ($\{$\code{terrible, broken, slow, useless, disappointed, ...}$\}$);
        polarity = positive$-$negative ratio.
  \item LSA: \code{TfidfVectorizer(max_features=1024, stop_words="english",
        ngram_range=(1,2))} then \code{TruncatedSVD(n_components=2,
        random_state=42)}. Returns 200 sample points $(x, y)$ plus the
        explained variance ratios.
\end{enumerate}
\end{algobox}

\predicts \code{customer_feedback} profiled. Top unigrams skew towards
positive seeds for non-defaulters and negative seeds for defaulters; LSA
scatter shows two soft clusters.

\subsection{\texttt{\textbf{drift\_analysis.py}} \textcolor{tealac}{\small\textsf{[compare two dataframes]}}}

\begin{libsbox}
\code{numpy}, \code{pandas}, \code{scipy.stats.ks_2samp},
\code{scipy.stats.chi2_contingency}.
\end{libsbox}

\begin{algobox}
\textbf{Numeric column.}
\begin{enumerate}
  \item Coerce to float, drop NaN/Inf.
  \item PSI on 10 quantile bins from the reference.
  \item Two-sample Kolmogorov--Smirnov (\code{ks_2samp}); flag at
        $p < 0.01$.
  \item Mean shift $z$ in pooled SD units.
  \item 20-bin histogram preview shared across ref + cur.
\end{enumerate}
\textbf{Categorical column.}
\begin{enumerate}
  \item PSI on category proportions (Laplace smoothed by $10^{-6}$ to
        avoid $\log 0$).
  \item Chi-square independence on a $2 \times K$ contingency table
        (top 30 categories).
  \item Lists new and missing categories.
\end{enumerate}
PSI severity: $<0.10$ stable, $<0.25$ minor, $<0.50$ moderate,
$\geq 0.50$ severe. KS upgrades a stable PSI to minor when significant.

\textbf{split\_by\_date}. Sorts by parsed date, cuts at \code{ratio}
(default 0.5), returns (older, newer). Used by \code{/api/compare-self}.
\end{algobox}

\predicts on \code{showcase_v3_full} self-compare with \code{ratio=0.5},
verdict is \emph{stable} (no concept drift). The v4 build's mid-2023
drift produces \emph{severe} PSI on \code{defaulted} and \code{interest\_rate}.
